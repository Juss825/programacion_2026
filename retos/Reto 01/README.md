## Descripción
Proyecto en C++ que implementa herencia usando una clase base Vehiculo
y varias clases derivadas como Coche, Moto, Camion y Autobus.

## Funcionalidades
- Creación de distintos tipos de vehículos
- Gestión y cambio de placas
- Uso correcto de herencia
- Mostrar información completa en consola
